# Java Shareit
### Описание
Данный проект создан в учебных целях (для изучения разработки backend приложений).

Пользователь приложения может выставлять различные вещи для сдачи в аренду, искать вещи, которые сам хочет арендовать 
и бронировать, бронь модерирует собственник. Если нужная вещь не найдена, есть возможность отсавить запрос. Пользователь 
может оставлять комментарии для вещей, которые он брал.

### Технологии
* Java
* Spring Boot
* JPA
* Hibernate
* SQL (PostgreSQL)
* Maven
* Docker
* Mockito, JUnit
